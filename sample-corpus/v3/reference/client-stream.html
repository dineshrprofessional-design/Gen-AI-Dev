Client.stream()

Opens a streaming connection and yields events as they arrive. The generator holds its connection open for the lifetime of the iteration, so callers must either exhaust it or close it explicitly. Abandoning a partially consumed stream leaks a connection until the pool reaper collects it, which by default takes ninety seconds.

Parameters

nametypedefaultrequired
payloaddict-yes
chunk_sizeint1024no
heartbeat_msint15000no
reconnectbooltrueno

Example

with client.stream(payload={"query": "hello"}) as events:
    for event in events:
        print(event.text, end="")

Notes

When reconnect is true the client transparently re-establishes a dropped connection and resumes from the last acknowledged event id. Duplicate events are possible across a reconnect boundary, so consumers should be idempotent.
