WHY v1 IS LENIENT — the diagnosis the change is built on
--------------------------------------------------------
The v1 criterion is "does it answer the question that was asked, FROM THE
CONTEXT IT WAS GIVEN". v1's reasons show it collapsing that into a single
weaker test: "is every sentence in the answer supported by some chunk?"

That test cannot fail an answer that is fluent, fully grounded, and about the
wrong thing. Its reasons say so almost verbatim:

  w6-020  "The answer correctly states the default `force` values for v2 (true)
           and v3 (false) as supported by the provided context."
           — true of every sentence. The question asked about `fail_fast`.

  w6-023  "The answer correctly explains using the `proxy` parameter of
           `Client.send()` as described in the provided context."
           — the PARAMETER is described; the CALL the answer shows is not.

  w6-024  "The answer correctly explains that chunk_bytes is set by passing it
           to Client.upload()" — true, and silently one of two documented
           chunk_bytes parameters with different defaults.

So the missing instruction is not "be stricter". It is: grounding of each
sentence is necessary but not sufficient; the answer must also be ABOUT the
thing that was asked, and must not present as documented what the docs do not
show.

PRINCIPAL RISK — how this could go wrong
----------------------------------------
Over-correction. Both few-shot examples demonstrate FAIL. A judge shown two
FAILs and no PASS may shift its threshold globally and start failing correct
answers. The exposed surface is the 15 currently-correct PASSes, especially:

  - the 7 `clean` cases, which v1 got 7/7 right. Any loss here is a real
    regression, not a rounding error.
  - the mode-1 cases (w6-002..w6-008), which are correct answers whose only
    defect is citation formatting — a criterion the prompt tells the judge to
    ignore. A judge nudged toward strictness may start counting it anyway.

FALSIFICATION — what would make this prediction wrong
-----------------------------------------------------
The prediction is WRONG if any of the following holds after v2 runs:

  1. Agreement <= 69.2% (no improvement, or a regression).
  2. Any of the 7 `clean` cases flips from PASS to FAIL.
  3. w6-020 or w6-023 still passes — the shown examples did not even fix
     themselves, which would mean few-shot examples do not transfer here at all.
  4. Agreement reaches 25/26 or 26/26 — that would mean the judge "fixed"
     w6-017/w6-018, which given the corpus evidence above could only happen by
     accident or by the judge reasoning wrongly to a right-looking answer.
     A higher number would be a worse judge.

I will report the outcome against these four conditions verbatim, including
any that fire.
